# Сборка данных для атласа

Папка `../data` собрана скриптами отсюда. В репозитории лежит только
результат — исходники Natural Earth весят под 80 МБ и в git не нужны.

## Как пересобрать

```bash
cd tools
mkdir -p geo && cd geo
B=https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson
for f in ne_10m_admin_1_states_provinces \
         ne_10m_populated_places \
         ne_10m_geography_regions_polys \
         ne_10m_geography_marine_polys \
         ne_10m_rivers_lake_centerlines \
         ne_10m_lakes \
         ne_50m_admin_0_countries; do
  curl -sSLo $f.geojson $B/$f.geojson
done
mv ne_10m_admin_1_states_provinces.geojson ne_10m_admin_1.geojson
cd .. && python3 build.py
```

Нужен только Python 3, внешних библиотек нет. Сборка занимает
секунд десять и перезаписывает четыре файла в `../data`.

## Что где

| Файл | Зачем |
|---|---|
| `build.py` | Собственно сборка: читает GeoJSON, проецирует, упрощает, пишет `../data/*.js` |
| `geolib.py` | Проекция Альберса, упрощение Дугласа-Пойкера, отсечение, сглаживание, центроиды |
| `regions_table.py` | Справочник 89 субъектов: названия, типы, столицы, округа |

## Почему справочник субъектов ведётся руками

Геометрия у Natural Earth хорошая, а вот атрибуты местами врут:
Москва и Московская область поменяны ISO-кодами, Алтайский край
подписан как Республика Алтай, столица Ингушетии указана Назрань
вместо Магаса. Поэтому названия, типы и столицы лежат в
`regions_table.py`, а с геометрией связываются по `adm1_code` —
единственному полю, которому можно доверять.

Четырёх субъектов — ДНР, ЛНР, Запорожской и Херсонской областей — в
российском разделе Natural Earth нет вообще. Их контуры лежат в другом
разделе набора, поэтому в справочнике у них коды с префиксом `UKR-`:
это внутренние идентификаторы записей Natural Earth, по которым идёт
связка с геометрией. Переименовать их нельзя — сборка перестанет
находить контуры.

## Источник и лицензия

[Natural Earth](https://www.naturalearthdata.com/) — public domain.
Масштабы: 1:10 000 000 для всего, кроме контуров стран-соседей
(1:50 000 000 — для фона подробнее не нужно).

Часть форм рельефа (Русская равнина, Тиманский кряж, Сибирские Увалы,
Хибины, Витимское и другие плоскогорья) в наборе отсутствует; их
контуры заданы в `build.py` вручную по школьному
физико-географическому районированию. Это генерализованные ареалы, а
не изолинии высот, — на карте о том сказано в легенде.
